# squares

## Requirements

- Node.js 24 LTS (`.nvmrc`)
- npm 11

## Project setup

```
npm ci
```

### Compiles and hot-reloads for development

```
npm run dev
```

### Compiles and minifies for production

```
npm run build
```

### Preview production build

```
npm run preview
```

### Lints and fixes files

```
npm run lint
```
